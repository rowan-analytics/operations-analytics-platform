# Retail Sales Performance Dashboard

## Project Overview

This project explores retail transaction data to analyse sales performance, customer behaviour, and product trends.  
The dataset was first prepared using SQL to clean and structure the data before being visualised in an interactive Power BI dashboard.

The goal of this project was to transform raw transactional data into meaningful business insights through data modelling, analysis, and visualisation.

---

## Data Preparation (SQL)

The raw retail transaction dataset was processed using SQL to prepare it for analysis.  
Several transformations were performed to ensure the data was structured and suitable for reporting.

Key steps included:

- Cleaning and filtering invalid transactions
- Handling missing or inconsistent values
- Calculating revenue fields from quantity and unit price
- Aggregating transactional data for customer and product analysis
- Creating summary tables for:
  - Top Customers
  - Top Products
  - Monthly Revenue

These SQL transformations allowed the dataset to be structured in a way that supports analytical queries and dashboard visualisation.

---

## Data Modelling & Analysis (Power BI)

The prepared dataset was imported into Power BI where additional analysis was performed using DAX measures.

Key metrics created include:

- Total Revenue
- Total Orders
- Average Order Value
- Revenue per Customer
- Revenue per Product
- Units Sold

Interactive filters and slicers were implemented to allow dynamic exploration of the data across different markets and time periods.

---

## Dashboard Structure

The Power BI report is divided into four analytical sections:

### Executive Overview
Provides a high-level summary of business performance including revenue trends, total orders, and key product insights.

### Customer Insights
Analyses customer behaviour and highlights revenue concentration among top customers.

### Product Analysis
Explores product performance including revenue distribution, units sold, and relationships between sales volume and revenue.

### Sales Performance
Focuses on geographic performance and market behaviour, comparing revenue and order volume across different countries.

---

## Key Insights

- Sales are heavily concentrated in the United Kingdom, which significantly outperforms other markets.
- A small number of customers generate a large proportion of total revenue.
- Certain products drive a disproportionate share of sales compared to others.
- Revenue and units sold show strong correlations across high-performing markets.
