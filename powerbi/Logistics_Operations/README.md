# 📊 Logistics Operations Dashboard (SQL + Power BI)

## 🚀 Overview
This project analyses logistics performance across regions, carriers, and customer segments using SQL and Power BI.

The objective was to identify operational inefficiencies impacting delivery performance and provide clear, data-driven insights to support decision-making.

---

## 📌 Key Insights
- On-time delivery performance stands at **51%**, with late deliveries at **49%**, indicating systemic inefficiencies rather than isolated issues.
- The **North region** shows the highest delays, driven by longer delivery durations.
- **Carrier performance varies significantly**, with high-volume carriers not always delivering better outcomes.
- **Retail customers drive the highest order volumes**, particularly in Central and East regions.

---

## 📈 Dashboard Features
- Executive overview of key KPIs (Orders, Returns, On-Time %, Delivery Days)
- Regional performance breakdown
- Delivery time distribution analysis
- Carrier performance comparison
- Customer segmentation analysis (Enterprise, Retail, Wholesale)
- Monthly trend analysis for on-time performance

---

## 🧠 Business Value
This dashboard highlights critical areas for operational improvement:
- Identifies underperforming regions and delivery bottlenecks
- Enables comparison of carrier efficiency
- Supports optimisation of delivery times and logistics strategy
- Provides a clear, executive-level view of performance metrics

---

## 🛠 Tools & Technologies
- **SQL** – data extraction, cleaning, and transformation  
- **Power BI** – dashboard design and visualisation  
- **DAX** – KPI calculations and performance metrics
