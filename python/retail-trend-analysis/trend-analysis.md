# Python Trend Analysis & Forecasting

This project demonstrates time series analysis techniques applied to a retail-style revenue dataset using Python.

The analysis focuses on:

- Trend identification  
- Variance and change analysis  
- Time-based comparisons  
- Rolling averages for operational insight  

The dataset is structured to simulate real-world monthly revenue tracking and can scale to live data pipelines.

---

## Technical Approach

The workflow includes:

1. Data loading and datetime conversion  
2. Chronological sorting  
3. Rolling average trend smoothing  
4. Clean matplotlib visualisation  
5. Exporting production-ready chart output  

**Key libraries used:**

- pandas  
- matplotlib
